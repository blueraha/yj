# 포켓몬 상성 도감 (비공식 팬 사이트)

포켓몬 이름(한글·영문)이나 도감 번호로 검색하면 타입 상성, 특성, 종족값, 포켓몬 챔피언스 랭크 배틀 순위와 메가스톤 채용률을 보여주는 정적 웹페이지입니다.

- 서버나 빌드 과정이 필요 없는 단일 `index.html` 파일입니다.
- 랭크 데이터 기준일: 2026-10-02 (레귤레이션 M-C)

## 데이터 출처
- 종족값·타입·특성 이름: [PokeAPI](https://pokeapi.co/)
- 랭크 순위·기술·메가스톤 채용률: [Pokemon Champions Battle Data](https://championsbattledata.com/)
- 특성 설명과 타입 아이콘은 이 사이트에서 직접 만든 것입니다.

## 고지
이 사이트는 Nintendo, Game Freak, The Pokémon Company, Creatures Inc.와 관련이 없으며 후원·승인을 받지 않았습니다. 포켓몬 및 관련 명칭은 각 권리자의 상표입니다. 비상업적으로 운영합니다.
